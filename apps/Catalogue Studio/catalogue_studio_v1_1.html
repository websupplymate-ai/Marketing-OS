Code shape

          
Fixed at 23 characters. Letters and digits never share a segment, so nobody has to decide between O and 0.

          
WW - SEC - SHI - 0042 - FIT - NVY
│    │     │     │      │     └─ Base colour   3 letters
│    │     │     │      └─────── Fit           3 letters
│    │     │     └────────────── Serial        4 digits, padded
│    │     └──────────────────── Product type  3 letters
│    └────────────────────────── Industry      3 letters
└─────────────────────────────── Group         2 letters

          
Group, industry, type and serial identify the design. Fit and colour are its variations, so they sit together at the tail and colour ends the code. Serial runs within group + industry + type, so security shirts number 0001 upward rather than 0731 upward.

AI Orchestration

      
Six modules decide how each image should be produced. None of them produce it — the Decision Engine returns a plan, and the execution layer consumes it.

      
Rules this engine holds to: nothing is chosen at random, nothing is hallucinated, no prompt is hardcoded, repair comes before regeneration, and memory learns decisions rather than pixels. Every choice is explained under Why.
